# Orion 전체 UI·UX 점검 및 개선

2026-09-25. 무채색 스타일을 기준으로 메뉴 전체, 목록·상세·관계 탭, 권한 부여, GitOps 변경 검토, 이력, 오류 화면을 점검했다. 실제 계정 대신 데모 데이터로 검증하며 운영 인증·인가 및 대규모 데이터 성능은 별도 범위다.

## 핵심 사용자 흐름

1. 사용자/조직을 검색 → 상세와 연결 관계 조회 → 역할 선택 → 영향 검토 → 적용 완료.
2. 역할 조회 → 사용자·조직 부여 또는 정책·만료 설정 → 연결 변화 검토 → 적용.
3. 리소스 목록에서 유형·상태 필터 → 같은 화면에서 diff 대화상자 → 전체 Sync 영향 검토 → 적용 → 이력.
4. 정책 상세에서 Git 변경 검토로 이동 → 리소스·엔드포인트 처리 설정 비교 → 검토 → 적용.
5. 리소스 행 또는 상세에서 이력 열기 → revision의 변경 전후 확인 → 현재 상태와 복원할 정의·영향 검토 → 해당 리소스만 롤백.

## 남은 개선과 백엔드 의존성

- 리소스별 이력과 롤백의 필드별 diff·현재 관계 영향도·revision 충돌 검사를 구현했다. API는 리소스 필터 및 before/after 기록, 리소스 단위 복원 계약을 지원해야 한다. 정책 롤백은 기존 전체 정책 범위 확인을 유지한다. 서버의 영향도 preview token, 부여 보존·참조 검증·원자적 적용은 백엔드에서 보장해야 한다.
- 실제 접근 가능 여부는 연결 관계만으로 단정하지 않는다. 정책 충돌·만료·조직 상속을 포함한 서버의 최종 권한 평가가 필요하다.
- 대규모 목록은 현재 수집 후 브라우저 검색 방식이다. 서버 페이지네이션·검색·정렬 API를 도입할 때 URL 상태를 그대로 전달하도록 확장한다.
- 정책 처리 handler별 사용자 친화적 변경 요약은 handler config 스키마 확정 후 추가한다. 현재 상세 설정은 펼쳐서 조회한다.
- 상태를 URL에 보존하므로 검색어도 주소에 남는다. 비밀값 검색은 제공하지 않으며 API 키 원문은 취급하지 않는다.

## 재현 가능한 검증

### 리소스별 이력 후속 개선

별도 동기화 이력 메뉴와 목록 상단의 전체 이력 링크를 제거했다. 각 리소스 행/상세에서 해당 종류·ID의 변경 이력만 표시하며 삭제 완료 항목도 이력을 조회할 수 있다. revision별 before/after, 최초 동기화 직전 기준 버전, 현재와 동일한 버전의 롤백 비활성화를 제공한다. 롤백은 현재 정의와 선택한 정의의 diff·연결 영향도 검토 후 그 리소스만 복원하며 revision 충돌과 참조 무결성을 검사한다. API는 리소스별 롤백 전용 경로를 사용하며 기존 전체 롤백으로 대체하지 않는다.

후속 검증: 단위 테스트 23개 및 관련 E2E 8개 통과. 리소스별 이력 격리, 다른 정의/부여 보존, 삭제 이력, 목록/상세 진입, 새로고침 후 이력 유지, 한국어·영어와 모바일 접근성을 확인했다. lint·타입·포맷 검사 및 production webpack build 통과. 핵심 상호작용 7개를 재실행해 런타임 오류 없이 최신 화면 8장을 캡처했다.

### 기존 전체 점검 기록

최종 결과: 38개 경로·28개 상세 탭 순회, 핵심 상호작용 7개 통과. 자동 접근성 검사를 실행한 22개 목록/메뉴 경로의 WCAG A/AA 위반 0건, 23개 목록/메뉴 경로의 모바일 가로 넘침 0건. 상세 화면 접근성·404·언어·오류·키보드 흐름은 기존 E2E도 함께 사용했다. 단위 21개, E2E 52개(최초 49/50 통과 후 실패 1개 수정 재검증 및 신규 2개 포함), 모의 API 5개 통과. 프로덕션 webpack 빌드와 lint·타입·포맷 검사 통과.

`docs/ux-review-results.json`에 화면 순회 기록을 남겼다. `ORION_UX_PRODUCTION=1`이면 빌드된 앱을 사용하며, `ORION_UX_INTERACTIONS_ONLY=1`은 기존 순회 결과를 유지하고 상호작용·스크린샷만 갱신한다.

`node scripts/ux-review.mjs`는 로컬 Next 서버와 Chromium을 실행하여 목록·상세·관계 탭·주요 사용자 흐름을 순회한다. 페이지별 접근성 결과, 모바일 넘침, 런타임 오류와 스크린샷은 `ORION_UX_OUTPUT` 경로에 저장한다. 선택적으로 `ORION_SCREENSHOT_FONT_DIR`에 로컬 Noto Sans KR fontsource 폴더를 지정해 캡처 글꼴을 보완할 수 있다. 자동 검사는 실제 사용자 테스트나 수동 스크린리더 검증을 대체하지 않는다.

단위 테스트는 롤백 시 현재 부여 보존 및 잘못된 참조 차단을 포함한다. API 모드의 운영 동작은 실제 서버 연동 전까지 완료로 판단하지 않는다.
