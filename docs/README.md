## 갱신 기준

- 화면 상태는 **구현됨 / 부분 구현 / 미구현**으로 기록한다. 구현됨은 프런트엔드·모델·어댑터 범위이며 운영 서버 연동 완료와 구분한다.
- 상세 구현 근거는 소스 경로로 연결한다. 일반 명세에 커밋·병합 순서나 일회성 PR 설명을 누적하지 않는다. 변경 이력은 Git과 PR에서 확인한다.
- 검증 실행 결과는 날짜별 기록에만 남긴다. 재현에 필요한 기준 커밋·PR은 그 기록에 둘 수 있으며 과거 통과 결과를 현재 보증으로 사용하지 않는다.
- API의 revision, 동기화 이력, 키 버전, 결재 스냅샷은 제품 계약이므로 개발 이력과 구분해 유지한다.
- 현재 요구를 바꿀 때는 화면 명세·API 계약·미완료 항목을 함께 검토한다. 문서 정리만으로 미구현 기능을 완료 처리하지 않는다.
