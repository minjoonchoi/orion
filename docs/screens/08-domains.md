# 업무 도메인과 Action

구현: M. Action은 업무 도메인 아래의 명시적 행위 단위이며 **단일 endpoint**를 참조한다. 페이지 하위 객체가 아니므로 서버 간 연동에서도 사용한다. 하나의 endpoint를 여러 Action이 참조할 수 있다.

## DOM-01 목록 — `/domains`

도메인 이름·ID 검색, 동기화 상태 필터, 이름·유형·식별자·상태·변경 검토/동기화. 이름을 누르면 상세로 이동한다. 업무 이름을 중심으로 탐색하며 모든 행위를 전역 actions YAML 하나로 관리하지 않는다.

## DOM-02 상세 — `/domains/{domainId}`

기본 정보: 이름, ID, 설명, 유형. 탭: **Action → 관계 → 동기화 이력 → YAML**. Action 표는 해당 domain의 로컬 Action과 상태를 보여주고 상세로 이동한다. domain YAML 안에 actions가 있어도 자식 개별 revision을 가진다.

## ACT-01 하위 목록 — `/actions[?parent={domainId}]`

독립 LSB 메뉴가 아닌 업무 도메인 하위/직접 URL 화면이다. 이름·domain 포함 ID·상태로 탐색한다. 페이지 상세의 Action 목록에서도 같은 상세로 이동한다. 같은 로컬 Action ID가 다른 도메인에 있어도 서로 다른 권한이다.

## ACT-02 상세 — `/actions/{domainId}~{actionId}`

| 영역             | 기능                                                                |
| ---------------- | ------------------------------------------------------------------- |
| 기본 정보        | 이름, 복합 ID, 설명, 유형                                           |
| 정책 탭          | 이 Action을 참조한 정책과 정책별 응답 필드·마스킹·unmask 규칙       |
| 관계 탭          | 소속 도메인, 단일 endpoint, 사용하는 페이지/정책 탐색               |
| 동기화 이력·YAML | 개별 revision, 원본 endpoint ref, 복원                              |
| 권한 평가 탭     | ACT-03. 특정 주체가 이 Action을 호출할 수 있는지와 응답 범위를 조회 |

응답 field의 path/type은 endpoint 원본 정의를 보여준다. 정책마다 같은 endpoint에 다른 응답 범위를 정의할 수 있다. 페이지 컨텍스트만으로 한 Action의 응답을 임의 변경하지 않는다. 페이지별 응답을 구분하려면 서로 다른 Action을 사용하고 각 정책에 명시한다.

## ACT-03 권한 평가 — 상세 내부 탭

입력: 주체 유형(사용자/조직/서비스 어카운트) 및 대상, 현재 Action. 결과: 허용/거부와 사유, 필드별 원문/마스킹/해제/제외/충돌, 근거 정책. 호출 가능 여부와 응답 필드 반환 여부를 분리한다.

| 상황                | 표시/판정 원칙                                            |
| ------------------- | --------------------------------------------------------- |
| 유효 allow 없음     | 거부. 빈 설정을 전체 허용으로 해석하지 않음               |
| 유효 deny 있음      | 해당 Action 호출 거부                                     |
| 여러 allow          | 허용 필드 합집합, 같은 필드는 마스킹 우선                 |
| unmask              | 다른 유효 allow의 필드 반환 권한에 대해서만 명시적 해제   |
| 비교 불가 마스킹    | 충돌/차단. 임의로 약한 규칙 선택 금지                     |
| 조회 오류/권한 없음 | 결과 없음/오류. ‘거부’라는 정상 평가 결과로 위장하지 않음 |

평가는 관리자용 검토 도구이고 실제 upstream 호출·응답 변환이 아니다. 사용자 플랫폼 역할과 기존 평가 graph가 현재 별도 모델이므로 최종 운영 인가와 동일하다고 표시하지 않는다.

## 검수

페이지 없이 Action 권한을 부여한 S2S 시나리오, 동일 endpoint를 공유하는 서로 다른 Action, 동일 로컬 ID의 다른 domain, 마스킹 해제 전용 정책을 각각 검증한다. 실제 요청은 서버가 인증된 호출자와 현재 플랫폼/키를 기준으로 평가해야 하며 화면에서 선택한 타인을 호출자로 신뢰하지 않는다.
