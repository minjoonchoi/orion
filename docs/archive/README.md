# 레거시 계약 참고

이 폴더는 이전 모델의 회귀·호환·이관 검토 자료다. 현재 제품 요구나 신규 API 구현의 기준으로 사용하지 않는다. 원래 변경 과정은 Git 이력에서 확인한다.

| 자료                                                         | 적용 범위                             | 현재 계약                                       |
| ------------------------------------------------------------ | ------------------------------------- | ----------------------------------------------- |
| [ResourceBundle / PolicyBundle](resource-bundle-contract.md) | 이전 YAML 파서·동기화 모델            | [정의 관리](../definition-management.md)        |
| [서비스별 키 발급 요청](api-key-request-contract.md)         | 이전 요청 메타데이터 API·키 이관 참고 | [결재·키 수명주기](../approval-key-workflow.md) |

운영 전에는 이전 데이터와 새 모델의 식별자·권한·이력 매핑을 명시적으로 검증한다. 새 계약으로 자동 변환되거나 운영 서버가 구현되었다고 가정하지 않는다.
