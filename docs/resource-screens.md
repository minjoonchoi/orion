# 리소스 조회 화면

> 이 문서는 작성 당시의 구현·계약 설명입니다. 최신 화면 기획과 변경된 진입점, master/후속 PR/미완료 구분은 [메뉴별 화면 기획서](screens/README.md)를 우선 확인하세요.

LSB의 기존 서비스·화면 그룹을 리소스로 변경했습니다. 하위 메뉴 경로는 유지합니다.

| 목록                 | 상세 정보                                           | 관계 목록  |
| -------------------- | --------------------------------------------------- | ---------- |
| `/services`          | 서비스 ID, 이름, 설명, 상태                         | 엔드포인트 |
| `/service-endpoints` | 엔드포인트 ID, 이름, 소속 서비스, HTTP 메서드, 경로 | —          |
| `/workspaces`        | 워크스페이스 ID, 이름, 설명                         | 페이지     |
| `/pages`             | 페이지 ID, 이름, 설명, 소속 워크스페이스, 경로      | —          |

상세는 각 목록 경로 뒤에 `/[id]`를 붙입니다. 서비스의 엔드포인트 탭은 `?tab=endpoints`, 워크스페이스의 페이지 탭은 `?tab=pages`로 공유하며 새로 고침과 뒤로 가기를 지원합니다. 잘못된 탭은 기본 정보, 없는 ID는 찾을 수 없음 화면으로 처리합니다. 기존 `/resources` 주소는 `/services`로 이동합니다.

모든 목록은 검색, 정렬, 페이지 이동을 제공합니다. 서비스는 상태, 엔드포인트는 서비스와 HTTP 메서드, 워크스페이스는 페이지 지정 여부, 페이지는 워크스페이스 필터를 제공합니다.

정책의 서비스·엔드포인트·워크스페이스와 조직의 관리 서비스에서 리소스 상세로 이동합니다. 서비스↔엔드포인트, 워크스페이스↔페이지를 양방향으로 탐색합니다. API/화면 경로는 등록된 리소스의 메타데이터로 표시하며 실제 대상 API를 실행하거나 대상 화면으로 이동하지 않습니다.

## 데이터와 검증

기존 서비스 예제와 공유 리소스 카탈로그(`src/features/resources/fixtures.ts`)를 정책 조회에도 사용합니다. 서버 페이지는 `resourceRepository`를 호출합니다. API 계약이 정해지면 이 조회 어댑터를 교체합니다. 현재는 가상 데이터 조회이며 생성·수정·삭제, 실제 인증·인가와 권한 상속은 포함하지 않습니다.

`npm run check`, `npm run build`, `npm run test:e2e -- --workers=2`로 검증합니다. 목록 탐색, 관계 이동, URL 탭 복원, 빈 관계와 없는 ID, 접근성 및 모바일 가로 넘침을 확인합니다.
