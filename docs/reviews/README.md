# 검증 기록

검증을 실행한 당시의 결과를 보관한다. 현재 화면 동작과 수용 기준은 [화면 기획서](../screens/README.md), 현재 통합 과제는 [미완료 목록](../screens/15-gaps-and-decisions.md)을 따른다.

| 기록                                        | 범위와 해석                                                                               |
| ------------------------------------------- | ----------------------------------------------------------------------------------------- |
| [UI·UX 점검](ux-review-2026-09-25.md)       | 2026-09-25에 시작한 점검과 이후 보완 기록. 단계별 결과이며 최신 제품 명세가 아님          |
| [CI 회귀 검증](ci-regression-2026-09-26.md) | 당시 브랜치별 테스트 결과와 실패 원인. 결과를 합산하거나 현재 HEAD의 통과로 취급하지 않음 |

새 실행 결과에는 실행일, 대상 revision/환경, 명령, 결과와 미검증 범위를 기록한다. 이전 기록을 덮어써 새 실행처럼 보이게 하지 않는다.
