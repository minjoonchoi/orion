# Orion 플랫폼 스타일

## 방향

따뜻한 미색·회색 바탕, 흰색 작업 영역, 짙은 포레스트 그린 포인트를 사용합니다. 강조색은 현재 메뉴·주요 작업·선택 상태에 집중합니다. 정보 밀도와 읽기 편한 대비를 유지하며 색면·그림자·둥근 모서리를 절제합니다.

| 역할        | 토큰           | 값        |
| ----------- | -------------- | --------- |
| 페이지 배경 | `--background` | `#f6f5f1` |
| 작업 영역   | `--surface`    | `#ffffff` |
| 사이드바    | `--sidebar`    | `#eeeee7` |
| 본문        | `--text`       | `#292e28` |
| 보조 텍스트 | `--muted`      | `#646b60` |
| 주요 작업   | `--accent`     | `#3f5948` |
| 경계선      | `--line`       | `#dedfd7` |

- 기본 모서리는 6px, 배지는 4px, 모달은 8px입니다.
- 알림은 얇은 중립 테두리와 왼쪽 상태선으로 표시합니다.
- 성공·주의·위험 색상은 각각 저채도 녹색·황토색·적갈색입니다. 상태 텍스트를 함께 표시합니다.
- 입력창 경계선과 포커스 표시는 장식용 경계선보다 강하게 유지합니다.
- 표의 행 간격은 12px 수직 패딩을 사용합니다. 선택 행은 hover 중에도 선택 배경을 유지합니다.
- 색상은 CSS 변수로 수정하고 새 컴포넌트에 파란색 상수를 추가하지 않습니다.

공통 토큰은 `src/app/globals.css`, 상태 토큰과 컴포넌트 스타일은 `src/components/ui/styles.css`에 있습니다.
