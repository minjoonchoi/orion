# 페이지 관계 탐색

연관된 이름은 상세 링크로 표시합니다. 목록의 관계 개수는 해당 상세 탭으로 이동하며, 0개도 빈 관계 탭을 확인할 수 있습니다. 모든 이동은 실제 URL을 가진 링크로 구현하여 키보드, 새 탭 열기와 브라우저 뒤로 가기를 지원합니다.

기존 탭에서 제공하던 사용자↔조직, 사용자·조직→역할, 조직→서비스·서비스 어카운트, 서비스↔엔드포인트, 워크스페이스↔페이지, API 키→결재, 결재→템플릿·사용자 관계에 다음 역방향 조회를 추가했습니다.

| 현재 상세    | 추가 관련 항목                        |
| ------------ | ------------------------------------- |
| 사용자       | 소유 API 키, 요청한 결재, 처리한 결재 |
| 조직         | 조직 API 키                           |
| 역할         | 연결 서비스 어카운트                  |
| 정책         | 정책이 연결된 역할                    |
| 서비스       | 연결 정책, 관리 조직                  |
| 엔드포인트   | 연결 정책                             |
| 워크스페이스 | 연결 정책                             |
| API 키       | 연결 서비스 어카운트                  |
| 결재 템플릿  | 템플릿을 사용한 결재                  |

관련 항목은 검색·이름 정렬·페이지 이동이 가능한 표로 표시하며, 연결 없음과 검색 결과 없음을 구분합니다. 기본 관계 탭을 중복해서 만들지 않고 빠진 역방향 관계만 상세 아래에 추가합니다.

`src/features/relationships/repository.ts`는 기존 예제 관계를 역조회합니다. 새로운 관계를 추정하거나 조직 역할·키 상태를 근거로 권한을 부여하지 않습니다. 실제 API 연동 시 역조회도 서버 검색·페이지 처리에 맞춰 교체해야 합니다.

API 경로와 외부 제품의 화면 경로는 메타데이터이므로 실행 링크로 바꾸지 않습니다. 실제 대상 URL 계약이 없는 상태에서 API 실행이나 잘못된 외부 이동을 제공하지 않습니다.

검증: 연결 대상과 상세 탭 URL, 키보드 Enter 이동, 뒤로 가기, 관련 목록의 빈 상태, 자동 접근성과 모바일 가로 넘침을 E2E로 확인합니다.
