# LSB 메뉴 구성

| 그룹        | 메뉴              | 목록 경로            |
| ----------- | ----------------- | -------------------- |
| 사용자·조직 | 사용자            | `/users`             |
| 사용자·조직 | 조직              | `/organizations`     |
| 역할·정책   | 역할              | `/roles`             |
| 역할·정책   | 정책              | `/policies`          |
| 서비스·화면 | 서비스            | `/services`          |
| 서비스·화면 | 서비스 엔드포인트 | `/service-endpoints` |
| 서비스·화면 | 워크스페이스      | `/workspaces`        |
| 서비스·화면 | 페이지            | `/pages`             |
| API 접근    | API 키            | `/api-keys`          |

그룹명은 비클릭 제목이며 메뉴는 항상 펼칩니다. 모바일은 2열로 그룹을 배치합니다. Orion 브랜드를 누르면 개요(`/`)로 이동하며, 개요도 같은 그룹과 메뉴를 표시합니다.

메뉴와 설명의 단일 원본은 `src/config/navigation.ts`입니다. 경로는 정확히 일치하거나 `/` 하위 경로일 때만 활성화합니다. 예를 들어 `/services/123`에서는 서비스만 활성화하며 `/service-endpoints`와 혼동하지 않습니다.

이번 변경은 메뉴와 목록 진입 경로 구성입니다. 목록은 API 연결 전 준비 중 화면이며 상세 화면, 상세 탭, 경로 표시와 엔티티 간 링크는 실제 목록/상세 구현 시 추가합니다. 서비스 어카운트는 조직 상세 내부에 배치할 예정입니다.

기존 `/resources`, `/access-grants`, `/audit-logs`, `/components` 경로는 직접 접속할 수 있지만 새 LSB에는 표시하지 않습니다.
