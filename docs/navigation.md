# LSB 메뉴 구성

| 그룹        | 메뉴              | 목록 경로             |
| ----------- | ----------------- | --------------------- |
| 사용자·조직 | 사용자            | `/users`              |
| 사용자·조직 | 조직              | `/organizations`      |
| 사용자·조직 | 서비스 어카운트   | `/service-accounts`   |
| 역할·정책   | 역할              | `/roles`              |
| 역할·정책   | 정책              | `/policies`           |
| 리소스      | 서비스            | `/services`           |
| 리소스      | 서비스 엔드포인트 | `/service-endpoints`  |
| 리소스      | 워크스페이스      | `/workspaces`         |
| 리소스      | 페이지            | `/pages`              |
| API 접근    | API 키            | `/api-keys`           |
| 결재        | 결재 템플릿       | `/approval-templates` |
| 결재        | 결재              | `/approvals`          |

그룹명은 비클릭 제목이며 메뉴는 항상 펼칩니다. 모바일은 2열로 그룹을 배치합니다. Orion 브랜드를 누르면 개요(`/`)로 이동하며, 개요도 같은 그룹과 메뉴를 표시합니다.

메뉴와 설명의 단일 원본은 `src/config/navigation.ts`입니다. 경로는 정확히 일치하거나 `/` 하위 경로일 때만 활성화합니다. 예를 들어 `/services/123`에서는 서비스만 활성화하며 `/service-endpoints`와 혼동하지 않습니다.

사용자·조직, 역할·정책, 리소스 그룹은 예제 데이터 기반 목록·상세 조회와 엔티티 간 이동을 제공합니다. 서비스 어카운트는 독립 목록·상세와 조직 상세 내부에서 조회합니다. API 키 목록·상세와 결재 이력 조회를 제공합니다.

기존 `/resources`는 `/services`로 이동합니다. `/access-grants`, `/audit-logs`, `/components` 경로는 직접 접속할 수 있지만 LSB에는 표시하지 않습니다.

결재 그룹은 결재 템플릿과 결재 목록·상세 조회를 제공합니다. API 키의 결재 이력에서 결재 상세로 연결됩니다.
