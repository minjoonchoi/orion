# 사용자·조직 조회 화면

사용자·조직 메뉴의 목록과 상세 화면을 제공합니다.

- `/users`: 이름·이메일·사번·ID 검색, 상태·소속 조직 필터, 이름·연결 역할 수 정렬, 페이지 이동
- `/users/[id]`: 기본 정보, 소속 조직, 직접 연결된 역할
- `/organizations`: 이름·코드·ID·설명 검색, 상태 필터, 이름·멤버 수 정렬, 페이지 이동
- `/organizations/[id]`: 기본 정보, 멤버, 서비스 어카운트, 관리 서비스, 직접 연결된 역할

상세 탭은 `?tab=organizations`, `?tab=members`, `?tab=service-accounts`, `?tab=services`, `?tab=roles`로 공유할 수 있습니다. 잘못된 탭은 기본 정보로 표시하며, 없는 ID는 찾을 수 없음 화면으로 안내합니다. 사용자와 조직의 관계는 서로의 상세 화면으로 연결됩니다. 목록 검색은 현재 로드된 예제 데이터 전체에 적용됩니다.

## 데이터 연결 범위

현재 `src/features/identity/fixtures.ts`의 가상 데이터를 사용합니다. 실제 사용자 정보, 인증 세션, 서비스 어카운트 자격 증명은 포함하지 않습니다. API 계약이 정해지면 서버 페이지에서 호출하는 `identityRepository`를 API 어댑터로 교체해야 합니다. 실제 인증·인가와 서버 검색/정렬/페이지 처리는 API 통합 단계의 범위입니다.

역할은 직접 연결만 표시합니다. 조직 역할의 사용자 상속이나 유효 권한 계산을 가정하지 않습니다. 역할·서비스 상세 화면과 데이터 생성·수정·삭제는 이번 조회 기능 범위에 포함되지 않습니다.

`npm run check`, `npm run build`, `npm run test:e2e`로 검사합니다. E2E에서는 목록 탐색, 관계 이동, 상세 탭 URL과 뒤로 가기, 빈 관계, 없는 ID, 접근성과 모바일 가로 넘침을 확인합니다.
